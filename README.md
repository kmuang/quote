# Quote Generator

A small, dependency-free quote generator. Choose a quote when you want one, then share its text and attribution using your browser's share sheet.

## Run

Open `index.html` in a browser. Sharing depends on browser support and is generally available on secure pages served over HTTPS or from localhost.

## Attribution

Some popular quotes in the collection have disputed or unverified attributions. The page displays author names only; verify wording and sources before republishing them.
